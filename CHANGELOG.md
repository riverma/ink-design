# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project
uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-19

First release of Ink, a calm design system for reading.

### Added

- Sixteen gray levels as the whole palette, and two modes, Paper and Night,
  each using six levels, softened by default and at the full range with
  `.ink-full` or on a grayscale display.
- Lora for reading and Atkinson Hyperlegible Next for the interface,
  self-hosted under the OFL.
- Components: button, chip, link, page, running head, folio, pager,
  progress, contents, end, prose with drop cap, quote and dinkus, card,
  list, field, input, checkbox, switch and notice.
- Thirteen drawn icons on a 24-unit pixel grid.
- Latin Extended font subsets.
- A themer for trying twelve other OFL typefaces, sizes, weights,
  leading and measure against a page of Walden.
- Gates: stillness (new), contrast at AAA, attention and offline.
- A documentation site with a paged reader demo, and an agent brief in
  `SKILL.md` and `docs/agents.html`.
